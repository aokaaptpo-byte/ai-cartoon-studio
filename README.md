# AI Cartoon Studio

## Project: Саргасс теңізі

Бұл жоба — Саргасс теңізі туралы 1 минуттық қазақ тіліндегі 3D мультфильм жасауға арналған.

### Негізгі талаптар
- Ұзақтығы: 60 секунд
- Стилі: сапалы 3D анимация
- Тілі: қазақша
- Кейіпкерлер: екі адам
- Дауыстар: қазақ тілінде
- Анимация: қозғалыс, мимика, ерін қимылы
- Нәтиже: MP4 видео

### Маңызды
- Ақылы API қолданбау.
- Алдымен тегін жұмыс істейтін прототип жасау.
- Кейіпкерлердің түрі мен дауысы барлық сахнада бірдей болсын.
